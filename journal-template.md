## Content Insights
HTTP Status Codes: Divided into 5 categories (1informational, 2success, 3redirection, 4client error, 5server error); commonly used: 200 OK, 201 Created, 301 Moved, 401 Unauthorized, 403 Forbidden, 404 Not Found, 500 Internal Server Error
Static vs Dynamic: Static returns files, manually updated, hard to maintain; Dynamic generated in real-time, database-driven, powerful but complex to develop and deploy
CMS Definition: Content management software, supports publishing/editing, separates content display, easy to maintain, supports collaboration
CMS Development: Static → Commercial → Enterprise → Open Source → Headless → Composable, moving towards multi-platform and front-end/back-end separation
Mainstream CMS: All PHP+MySQL, open-source and free; WordPress easy to use, strong ecosystem, suitable for small and medium sites; Joomla moderate, suitable for medium projects; Drupal highly customizable, high threshold, suitable for large sites
WordPress Evolution: Since 2003, added themes, custom types, REST API, block editor, full-site editing, from blog to full-featured site building
Selection Conclusion: For CMS, excels in site management/extension/collaboration, requires server, slightly higher cost, choose according to needs
